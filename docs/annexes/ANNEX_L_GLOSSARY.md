| Term / Acronym | Full Form / Definition | Contextual Usage in AURORA |
| :--- | :--- | :--- |

| **Lucide React** | Feather-Inspired Iconography Library | UI icon set utilized throughout the AURORA responsive web interface. |

| **WAL** | Write-Ahead Logging | PostgreSQL logging technique ensuring data integrity and enabling point-in-time recovery. |
| **WBS** | Work Breakdown Structure | Hierarchical decomposition of the total project scope into manageable deliverables. |
| **XSS** | Cross-Site Scripting | Web security vulnerability mitigated in AURORA through React JSX escaping and CSP. |
